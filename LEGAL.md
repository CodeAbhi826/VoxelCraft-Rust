# Legal — VoxelCraft

Short version: **VoxelCraft is an unofficial, from-scratch fan recreation of
the 1.16.5-era reference game's gameplay rules**, built clean-room from
published documentation. It is **not affiliated with, endorsed by, or
connected to** any other game or studio. No third-party game assets, code,
or trademarks are included in this repository — the audit script
(`scripts/legal_audit.py`, run in CI) enforces that on every push.

This file is the user-facing summary. The **binding policy** with the full
rule set (L1–L8), audit history, and rationale is
[docs/LEGAL-COMPLIANCE.md](docs/LEGAL-COMPLIANCE.md). The project licence is
Apache-2.0 — see [LICENSE](LICENSE).

## Enforcement

`scripts/legal_audit.py` runs on every CI push: it scans shipped files for
third-party trademark text and per-pixel image-processing patterns
(creator-side pipelines may analyze; shipped code may never read or write
reference pixels), runs a self-test on every invocation, and guards the
provenance claims above.
