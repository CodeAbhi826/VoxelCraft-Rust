# Legal Compliance Policy — VoxelCraft

**Status: FULLY AUDITED AND ENFORCED. This round (2026-09-20) removed every
item that did not meet the bar below.**

This is the binding legal policy for the VoxelCraft project. It exists so
that every contributor can answer "is this legal?" with a rule, not a
guess. The project owner's directive is the top of the hierarchy:

> Never use copyrighted reference material directly — never copy, never
> trace, never modify-and-ship. Only build independently authored
> similar-in-spirit work, and keep everything legal.

---

## 1. What this project ships (provenance of every byte)

| Asset class | Provenance | License |
|---|---|---|
| Block / item / entity / GUI textures (`voxelcraft/assets-vault/**`, `builtin-pack/**`, `builtin-packs/**`) | Procedurally synthesized in-project from measured values (colorimetry, dimensions, animation timing) — pixel-level original work | Project license (Apache-2.0) |
| GUI dim overlays (`menu_background.png` etc.) | Flat single-color alpha fills generated by `scripts/regen_gui_fills.py` — a functional fill carries no creative expression | Project license |
| Embedded font (`Voxelfont.ttf`) | Generated by `scripts/make_voxelfont.py` from this project's own clean-room 5×8 bitmap glyph table (`ui.rs` FONT: decades-old industry-standard 5×7 LCD-style shapes for ASCII + in-project lowercase + in-project symbol extras) | MIT — see `crates/vc-render/assets/VOXELFONT-NOTICE.txt` |
| Sound / music | Original synthesis (no third-party audio) | Project license |
| Code | Original Rust implementation | Apache-2.0 |
| Game mechanics, formulas, timings, registry data | Facts are not copyrightable (17 U.S.C. §102(b)); values were re-derived from published documentation and verified live | n/a (facts) |

**No file in this repository is copied, traced, color-picked-from, or
derived from any third-party rightsholder's assets.** The 2026-09-20
forensic audit verified this at the byte and pixel level (see §4).

## 2. The clean-room rule (how "similar but legal" is defined)

* **Study the idea, author the expression.** Functional facts (a texture is
  16×16, a fuse burns 1.5 s, a slot grid is 9 wide, a button is 200×20) are
  free for anyone. The specific pixel arrangement, the specific glyph
  curves, the specific audio waveform are NOT — ours are always authored
  from scratch.
* **Genre conventions are shared property.** Hearts in the corner, a hotbar
  row, blocky terrain, pixel UI fonts — scènes à faire of the voxel genre,
  used by every game in the space.
* **Look-alike ≠ copy.** The goal is a familiar feel at ~90-95% recognition,
  achieved by independent authorship of the same functional roles — never by
  copying pixels and adjusting them.

## 3. Trademark and branding rules

* The project ships **no third-party trademarks** — no names, logos, fonts,
  splash texts, folder conventions, or marketing labels of any other game or
  studio appear in anything this project writes.
* **Our own vocabulary** covers every coined term we need (fuseling,
  voidling, the Hollow, fluxstone, scarlet/viridian wood, spirit sand,
  Voxelfont, …). The rename map lives in `scripts/gen_legacy_aliases.py`.
* Update-marketing names, edition names, and studio names never appear in
  code, docs, commits, or UI text.

## 4. What the 2026-09-20 audit found and fixed

A full-repo forensic scan (SHA-256 of every file + decoded-pixel comparison
of every PNG against the owner's study-only reference set) found:

1. **Three pixel-identical GUI overlay files** (flat black alpha fills,
   originally saved from the reference set). Regenerated from our own
   generator — provenance is now 100% in-project.
2. **A third-party derived-styled pixel font** (SIL-OFL licensed, so
   redistribution was technically permitted). Its derived look still did
   not meet this project's zero-third-party-expression bar. Replaced by
   **Voxelfont**, generated from our own glyph table.
3. **Scraped wiki page dumps** (process artifacts from the research phase).
   Deleted from the tree and purged from git history. The engine itself
   never needed them.

Post-fix verification: **0** byte-identical copies, **0** pixel-identical
PNGs, **0** trademark-name occurrences in any shipped file (code, assets,
packs, docs, CI).

## 5. Interop with the wider ecosystem (read-side only)

The engine loads **user-supplied** resource packs, data packs, shader packs,
and saves. This is format interop — the same legal principle that lets any
spreadsheet open a .xlsx. Rules:

* **We read, we never write.** The ecosystem's file layouts (`assets/<ns>/…`,
  `pack.mcmeta`, `data/<ns>/…`) are accepted as INPUT formats only. Our own
  packs use our own layout (`blockstates/`, `models/`, `textures/`,
  `pack.json`).
* **Namespace-agnostic by design.** No external namespace string is
  hardcoded anywhere; whatever folder prefix a user pack carries, it
  resolves onto our flat key space (`crates/vc-pack/src/pack.rs`,
  `NsAliasSource`).
* **Legacy-name aliases are interop data, not branding.**
  `crates/vc-pack/src/legacy_aliases.rs` maps the ecosystem's coined names
  (as bare, namespace-stripped keys) onto our vocabulary so real-world packs
  keep loading. The table is generated (`scripts/gen_legacy_aliases.py`),
  read-side only, and never rendered to users.
* **Compatibility statements are nominative fair use.** Docs may say
  "supports BSL/SEUS-format shader packs and labPBR-spec resource packs"
  the same way a media player says "plays MP4". No pack is ever bundled.

## 6. Enforcement (how the rules stay true)

* `scripts/audit_tools.py` (repo root) — the trademark/copyright scanner
  used for the audit; run it before any release.
* Pixel-identity check — decode-and-compare against the reference set
  before any asset release (the reference set itself stays OUTSIDE the
  repository at all times).
* CI gate: `ci.yml` runs the audit scanner on every push.

## 7. Distribution notes

* Game mechanics and data (formulas, timings, recipes, registry names) are

* All assets are original works of this project and ship under the project

* This project is not affiliated with, endorsed by, or connected to any
  other game or studio. No similarity in gameplay feel is a claim of origin.
