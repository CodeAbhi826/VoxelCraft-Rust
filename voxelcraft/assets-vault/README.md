# assets-vault — the clean-room modern asset library

**What this is:** a complete, original, procedurally-synthesized asset set
covering **every texture in the owner's modern-version reference dump**
(3,855 PNGs + 176 `.mcmeta` across block / entity / item / gui / particle /
trims / painting / mob_effect / map / misc / environment / font / colormap
/ effect), generated by the clean-room pipeline in `scripts/`:

```
upload/textures.zip  ──(vault_analyze.py: MEASUREMENTS ONLY)──▶  spec/spec.json
spec/spec.json       ──(vault_synthesize.py: 100% code-drawn)──▶  textures/**.png
output + reference   ──(vault_verify.py + legal_audit.py)─────▶  [PASS]
```

**What it is NOT:** it is *not* wired into the engine. No crate, no
loader, no build step references this directory (verified by grep — see
docs/ASSETS-VAULT.md). It exists as the owner's own asset library, ready
for future versions / future engines that want a modern-format set with
the same naming tree.

## Legal posture (binding — see docs/LEGAL-COMPLIANCE.md)

* Every pixel is **drawn by our own code** from *measurements* of the
  reference set (dimensions, palette histograms, aggregate statistics,
  animation metadata) — never from reference pixels. The reference zip
  never leaves `upload/` and is never opened by the synthesizer.
* Result: **same names, same dimensions, same palette families, same
  structural conventions** (planks have boards, ores have blobs, buttons
  have bevels) — but **independently generated pixel expression**
  (different speckle, different blob placement, own dithering, own icon
  art). That is the maximum similarity the law allows; a pixel-identical
  copy or a trace is a derivative work and is categorically excluded.
* The two `gui/title/` logo slots carry **our own abstract artwork**
  (nothing resembling the trademarked wordmarks — pixel-distinctness is
  asserted by `scripts/legal_audit.py`).
* Paintings are **original compositions** (the most-protected category
  in the reference set).
* The font pages render **our own OFL-licensed Monocraft** (Idrees
  Hassan, SIL OFL 1.1) into the page grid; the fictional alphabets
  (`ascii_sga`, `asciillager`) are our own original glyph sets.

## Regenerating / verifying

```
python3 scripts/vault_analyze.py     # reference -> spec (measurements)
python3 scripts/vault_synthesize.py  # spec -> all 3,855 PNGs (~10 s)
python3 scripts/vault_verify.py      # metrics + coverage report
python3 scripts/legal_audit.py       # MUST print [PASS]
```

## Similarity report (honest numbers)

Per-category aggregates live in `spec/verify_report.json`. Summary
(see docs/ASSETS-VAULT.md for interpretation):

* names / dimensions / animation metadata: **100% coverage**
* byte-identity vs reference: **0 matches** (required)
* palette-family + luminance-profile match: high for tile families
  (blocks, GUI), medium for high-color art (entity skins, paintings —
  by design, see the report)
* pixel-identity: low everywhere except trivially-simple tiles — this
  is the legal boundary, not a defect.
