------------------------------------------------------------------
PROVENANCE (clean-room statement)
------------------------------------------------------------------
Every glyph in Voxelfont.ttf was generated programmatically from this
project's own clean-room 5x8 bitmap glyph table (vc-render/src/ui.rs,
const FONT). The bitmap set uses the decades-old industry-standard 5x7
LCD-style shapes for ASCII capitals/digits (in continuous common use
in display controllers since the 1970s) plus lowercase glyphs designed
from scratch inside this project. No third-party font file was read,
copied, traced, transformed or bundled at any point of the pipeline.

Regenerate with:  python3 scripts/make_voxelfont.py
